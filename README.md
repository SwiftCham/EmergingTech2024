# EmergingTech2024
Repository for Emerging Tech Module

this repository focuses on two key elements: A text processor in python which generates words based on a set of given texts, and the other is a recreation of the classic ELIZA Chatbot,  made in simple javascript and html.
The repository has the goal of expanding on the ideas behind the mass growth of LLM's and AI in recent years, by going back to the roots of what helped create them.
Below are key features and usage patterns for the repository




### Key Features
- **Text Preprocessing**: Functions to clean and preprocess text data.
- **Trigram Model**: Implementation of a trigram model to generate text based on input data.
- **JSON Export**: Functionality to export trigram counts to a JSON file.
- **Chatbot**: A simple chatbot inspired by the ELIZA program.

### Usage
1. **Text Preprocessing**: Load and preprocess text data in a folder called englishworks to remove unwanted sections.
2. **Trigram Model**: Use the trigram model to generate text based on the preprocessed data.
3. **JSON Export**: Export the trigram counts to a JSON file for ease of use in future projects.
4. **Chatbot**: Interact with the ELIZA-inspired chatbot using the below pages website link, start wiith saying "hi"! :3.
